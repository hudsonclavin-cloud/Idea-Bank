Aloft

A tiny language with no variables. To remember a value, throw it. The height is how long you'll need it.

Output

Each arc is one value in the air, from the beat it is thrown to the beat it lands. The program's memory at any moment is the arcs crossing that moment.

Language reference

A program is some balls lines, then one or more beats. A beat starts with a catch line and runs until the next one. Beats repeat in a loop: at time t = 0, 1, 2, … the beat numbered t mod n runs, where n is the number of beats.

balls 0 1           # values already in the air, in landing order
catch a b           # this beat catches two balls
  let s = a + b     # a name for the rest of this beat
  say a, s when a < 9   # print a line (optionally only when…)
  stop when a > 50  # end the run (optionally only when…)
  throw b up 1      # lands at t + 1
  throw s up 1
  • A throw at time t with height h lands at time t + h. Heights are numbers written out, 1 to 9999. Every beat throws exactly as many balls as it catches, and throws can't have when.
  • Balls that land together are caught in the order they were thrown (earlier throw first; thrown on the same beat: in the order of the throw lines).
  • Names last one beat. A name is bound by catch or let and is gone when the beat ends. Nothing else remembers anything.
  • balls lists the values in the air when the program starts, as if the pattern had always been running, in the order they will be caught.
  • Before it runs, the checker makes sure every name is in hand, every beat throws what it catches, every beat receives exactly the balls it catches (a throw on beat i, height h, lands on beat (i + h) mod n), and balls lists exactly (sum of heights) / n values.
  • Numbers are whole, of any size below 24096. / and % round down (−7 / 2 = −4, −7 % 2 = 1). Comparisons, and, or, not give 1 or 0, and 0 is false. if c then x else y picks a value. min(a, b, …), max(a, b, …), abs(x).
  • Precedence, loosest first: if … then … else; or; and; not; == != < <= > >= (no chaining); + -; * / %; unary -.
  • Lines: one statement per line; a line break inside brackets is ignored; # starts a comment; say joins its items with spaces.
