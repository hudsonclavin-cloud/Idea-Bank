Groundskeeping

What is going on?

Every dot is a person walking from one door to another. Each follows four rules:

  1. Head for your door.
  2. Drift toward trodden ground you can see, but never more than 64° off your bearing.
  3. Every step wears the grass a little.
  4. Grass grows back.

At first everyone walks straight, so the lawn gets the straight lines between every pair of doors. Then paths start pulling on each other. Where two paths run close, walkers on each drift toward the other, the paths merge, and the merged path is more worn and pulls harder still. The network shrinks into one that nobody designed: a bit longer for each walker, far shorter in total.

Try: watch Three gates for a minute. Then push Grass memory to either end: with long memory the first paths get locked in; with short memory the network shrinks to a single junction. Plant a hedge across a busy path. Pave the worn paths and let the rest grow back.

The lawn is 100 m across. Time is counted in ticks: a walker crosses the lawn in about 350, and Grass memory is how many ticks a footprint takes to fade to about a third.

Based on the active walker model of Helbing, Keltsch & Molnár, Modelling the evolution of human trail systems, Nature 388 (1997). Keys: Space plays or pauses, 1 to 4 pick a tool.
