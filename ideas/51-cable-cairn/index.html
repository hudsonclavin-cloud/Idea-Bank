02 / FROM FILE TO DESK

Print flat. Lift into place.

  1. Measure the outside of the cable, including its jacket. Leave space for the cable to slide; this design does not snap around it.
  2. Download the STL and open it in a slicer as millimetres. Put the broad, flat base on the bed, with Z pointing up.
  3. A starting point for a 0.4 mm nozzle: PLA, 0.2 mm layers, 3 perimeters and ordinary infill. The channels have no roof, so this geometry needs no supports.
  4. Try a two-channel print first if fit matters. A light plastic corral can move when tugged; optional removable tape beneath the base can keep it in place.
