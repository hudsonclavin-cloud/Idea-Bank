A two-layer cellular automaton, not a model of physical time. The last two rings contain all the information needed to undo a step.

The rule beneath the print

Each new ring is yesterday XOR (today’s left neighbour XOR today’s right neighbour). To reverse, swap yesterday and today, then apply the same XOR. The edges join in a loop. The picture keeps recent rows as ink; the inverse calculation uses only its two current rings.
