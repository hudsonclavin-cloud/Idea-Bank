Autogram Forge

An autogram is a sentence that counts its own letters, and gets every count right. You write the opening words. The forge searches for an ending that makes the whole sentence true.

Why this is hard

Every number you write is made of letters. Correct the count of e from twenty-seven to twenty-eight and you swap s, e, v, e, n for e, i, g, h, t: the sentence now has one fewer e, plus different counts of s, v, n, i, g, h and t, so those claims break in turn. Step through the number words to see what each change costs:

→

So a true sentence is a fixed point: a set of claims that, once written out, produces exactly those counts. The forge looks for one by a random walk. It picks a false claim, moves it part of the way toward the count the sentence really has, re-counts, and repeats, up to a few hundred thousand times a second.
