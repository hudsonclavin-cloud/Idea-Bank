The Forgiving Code

One wrong letter in a codon usually lands you on a similar amino acid. Deal the amino acids out at random and that luck vanishes. It is one-in-ten-thousand luck.

A ribosome reads messenger RNA three letters at a time. Each codon is matched by a transfer RNA whose anticodon pairs with it, and that tRNA carries one amino acid. Sixty-four codons stand for twenty amino acids and stop, so the dictionary repeats itself. This page is about something less obvious than the repeats: the arrangement. Codons that differ by one letter tend to mean chemically similar amino acids, so a copying error or a misread lands softly. Keep every repeat, shuffle only which amino acid each block of codons gets, and almost every shuffle is harsher than the real thing.

Each random code keeps the real code's skeleton: the same twenty blocks of synonymous codons, the same three stop codons. Only which amino acid goes to which block is shuffled, so there are 20! ≈ 2.4 × 1018 of them. The histogram scores a sample of them with the measure you chose above.

A real human mRNA takes random single-letter typos, one at a time. Both panels read the same mutating message; only the dictionary differs. 4 · What is being measured, and what is not

The measure

Take every single-letter change that turns one sense codon into another sense codon. There are 526 of them (263 pairs; changes into a stop codon are left out, as Haig and Hurst left them out). For each, square the change in the amino acid's property. Average. With polar requirement and every change counted once, the real code scores 5.19; that is Haig and Hurst's MS0. The "weighting" option is Freeland and Hurst's: transitions (purine↔purine, pyrimidine↔pyrimidine) count more than transversions, and the second codon position, which they take from the mistranslation literature to be the one ribosomes misread least, counts least: weights 1 / 0.5 / 1 for transitions and 0.5 / 0.1 / 1 for transversions at positions 1 / 2 / 3. Under that weighting the real code scores 2.63 and beats all but a few in a million shuffles.

Why the third letter barely matters

Of the 526 changes, the 176 at the third position are silent 126 times (72%): half of the sixteen boxes mean one amino acid whatever the third letter, and most of the rest split two-and-two by whether that letter is a pyrimidine (U, C) or a purine (A, G). At the second position no change is ever silent, and the second-position score of the real code is by far the worst of the three. In Freeland and Hurst's weighting that is also the position misread least, while the third, where Crick's wobble pairing lives, is misread most. The shuffle keeps all of this, which is why both storm panels show identical silent counts. What the shuffle destroys is the pattern between blocks: in the real code, the five amino acids with U in the middle of their codons are all hydrophobic, and neighbouring boxes tend to hold neighbouring chemistry.

Better than almost every shuffle, but not the best

"One in ten thousand" is not "optimal". Press Improve the alternative: six thousand proposed swaps of two amino acids usually find a code scoring about 3.5 on the unweighted measure (in forty trials from random starts, the median was 3.52 and the worst 4.29), a third better than the real code, and about 1.5 to 1.8 on the weighted one. Longer searches never went below 3.49 and 1.49. The first is known to be the best possible: Goldman (1993) found a code this good with a different search, and Buhrman and colleagues (2011) proved that no code with these blocks and stops does better on this measure. For the weighted measure, 1.49 is only the best found here.

Where the pattern came from is still argued. Crick (1968) called the code a "frozen accident": whatever assignment existed when life came to depend on it was locked in, because changing it would have altered every protein at once. Haig and Hurst read their own result as selection against errors. Others see a by-product of how the code grew: new amino acids taking over codons from the amino acids they are made from (Wong 1975), direct chemical affinities between some amino acids and their codons (Yarus and colleagues 2009), or chemically similar amino acids being added next to each other, which would lower the score with no selection for it at all (Massey 2008). Novozhilov, Wolf and Koonin (2007) describe the real code as partly optimized, about halfway up a modest peak, a mix of adaptation and frozen accident. This page measures the pattern; it does not settle where the pattern came from.

Simplifications
  • Random codes keep the real code's block structure and stops (the standard convention since Haig & Hurst 1991). The redundancy itself is never tested, only the arrangement of amino acids over it.
  • One property at a time. Polar requirement is a 1966 paper-chromatography measure of how an amino acid partitions between water and an organic solvent, and it is the property on which the real code looks best. Haig and Hurst also tested hydropathy, molecular volume and isoelectric point; their abstract singles out polar requirement and hydropathy. Recomputed with this page's method, the pattern is clear for hydropathy, weak for molecular volume (roughly 1 random code in 10 does better, on either of two common volume scales) and absent for isoelectric point (more than half do better). Try the hydropathy option here (Kyte & Doolittle's scale). With every typo counted equally the real code is still rare, about 1 in 130, but far less so than for polar requirement. Under the Freeland & Hurst weighting it is about 1 in 10,000, against a few in a million for polar requirement.
  • The squared change is a cost, not a fitness. Nothing here knows whether a protein still folds.
  • Typos in the storm hit codons uniformly and never insert or delete a letter. Real mutation and misreading spectra are biased, and real genes use some synonymous codons far more than others, which changes the effective score of the code in use.
